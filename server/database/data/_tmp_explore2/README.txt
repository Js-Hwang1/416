## Sources
Election results from Massachusetts Elections Division

Precinct boundaries primarily from MassGIS (https://www.mass.gov/info-details/massgis-data-2022-wards-and-precincts)

Additional boundary data was obtained, either through municipal websites or contact with an official, in the following cities or towns: Chicopee, Dracut, Hingham, New Bedford, Newburyport, Peabody, Revere, and Warren. In Chicopee and Revere, all precincts were swapped with a new file. In the other municipalities, additional precincts not found in the MassGIS file were created based on the new data.

The precinct boundaries were all checked against the L2 voter file closest to the November 2024 general election. The date of this voter file is February 26, 2025.
